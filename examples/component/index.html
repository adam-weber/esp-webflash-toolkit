ESP Flasher Component

Drop-in web component for ESP32 firmware flashing

Compact Mode (default)

Renders a single button. Click to open the flash UI in a modal.

<esp-flasher
    firmware="https://github.com/user/repo/releases/latest/download/firmware.bin"
    chip="esp32s3"
    fields="wifi"></esp-flasher>
Live Demo

Full Mode

Renders the complete flash UI inline as a card.

<esp-flasher
    firmware="https://github.com/user/repo/releases/latest/download/firmware.bin"
    chip="esp32"
    fields="wifi,device_name"
    mode="full"></esp-flasher>
Live Demo

Config URL

Load a v2 flash-config.json from a URL. Supports multiple variants, branding, and post-flash instructions.

<esp-flasher
    config="https://raw.githubusercontent.com/user/repo/main/flash-config.json"
    mode="full"></esp-flasher>

JavaScript Events

Listen for events on the element.

const el = document.querySelector('esp-flasher');

el.addEventListener('esp-flasher:connected', (e) => {
    console.log('Connected:', e.detail.chipType);
});

el.addEventListener('esp-flasher:complete', () => {
    console.log('Flash complete!');
});

el.addEventListener('esp-flasher:error', (e) => {
    console.log('Error:', e.detail.message);
});

// Programmatic access to internal ESPFlasher
el.flasher.setConfig({ wifi_ssid: 'MyNetwork' });
